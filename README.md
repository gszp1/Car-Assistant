# Aplikacja asystent samochodowy
Skład grupy: Michał Czajor, Mateusz Grzybek  
## Opis
Aplikacja, która zastępuje komputer pokładowy w autach bez systemu multimedialnego: telefon umieszczony w uchwycie działa jak ekran samochodowy z dużymi przyciskami i szybkim dostępem do nawigacji, muzyki i połączeń przez zewnętrzne aplikacje. Aplikacja jest również wyposażona w statystki takie jak np. Średnie zużycie paliwa, przejechany dystans w danym okresie. Przypomina też o serwisie według daty lub przebiegu i pokazuje informacje pogodowe istotne dla bezpieczeństwa jazdy.  
## Technologia
Kotlin  
Android Jetpack  
## Planowana funkcjonalność
Uruchamianie nawigacji, aplikacji do odtwarzania muzyki  
Statystyki związane z korzystaniem z samochodu  
Poziome GUI wygodne w użytku w czasie jazdy  
## Opcjonalne rozszerzenia
Panel pogodowy  
System powiadomień(ostrzeżenia pogodowe, konfigurowalne powiadomienia)  
Automatyczna zmiana między trybem dziennym a nocnym  
Zapamiętanie miejsca parkowania(GPS)
